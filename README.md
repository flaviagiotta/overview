# Overview

A personal finance overview built around how I think about my own savings: money I can spend, money that is locked at a fixed rate, and money invested in the market.

## Status

Work in progress.

- [x] **Spendable**: monthly balance forecast with warning and STOP alerts
- [ ] **Locked**: fixed-rate savings with compound growth
- [ ] **Invested**: market simulation

## Run it locally

    pip install streamlit pyyaml pandas numpy plotly pytest
    python3 -m streamlit run app.py

## Run the tests

    python3 -m pytest

## Disclaimer

This project is for information and simulation only. It is not financial advice.
